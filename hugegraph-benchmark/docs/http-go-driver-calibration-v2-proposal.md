当前已完成真实HG全11题功能验收与两轮同资源40rps比较。两轮均保留质量失败；002的大字符串两次Go测量分别拒绝558/26次到达，整workflow I/O和JVM生命周期GC也有较大差异。现有记录可以说明观察到的压力，尚不能把服务端等待、IF4准入和执行器成本分别归因。

## 交付与证据范围

新增一个受CLI调度的fixture组件和对应独立reader，环境类型明确为`http-generator-calibration`。实际发送HTTP、完成全部答案校验、保存每个计划到达和资源证据，不能用模型或手填passed替代。此组件不连接HugeGraph，不产生图数据库性能结果，也不取代真实HG功能、A/A、正控制、观测成本、正式比较或SF100验收。

服务只接受冻结的11题请求，返回由现有独立题集参考生成器生成并核验的完整结果。identity与gzip两种实际线上编码分别测试，固定原始响应字节和摘要；gzip在准备阶段生成，测量期间只发送预制字节。未知请求明确失败。固定HTTP/1.1、Content-Length、keepalive及现有超时/连接语义；provider每次运行的进程、来源和资源必须可核验。

复用现有Go runner、raw reader、资源采集、宿主观察、任务截止/取消和离线JSON/HTML，保持完整检查与有界writer。CLI提供清楚的help、dry-run/计划、机器可读状态和后续操作；不会把fixture类型包装成HugeGraph环境。fixture自己的负载、发送失败或资源压力使相应驱动结论保持未知/失败。

## 首轮预声明规模与资源

| 项目 | 固定方案 |
|---|---|
| 驱动题目 | 全11题，identity/gzip分别覆盖，22个单元/臂 |
| 负载 | open 80rps，覆盖当前正式曲线最高预定速率；更高率另需证据 |
| 并发与时限 | IF64、原请求/排空限制；与已有capacity policy的IF64相同 |
| 驱动资源 | 对照4CPU/6CPU，均3GiB、GOMAXPROCS=4；独立资源限制真实实施 |
| 固定响应服务 | Node22、1CPU/512MiB、预加载只读资产，独立于driver cgroup；不用测量期压缩消耗模拟后端能力 |
| 顺序与重复 | 两个block：4→6、6→4；共4个新driver容器，worker/goroutine不当作重复 |
| 每单元 | 预热30秒、测量60秒；每次4800测量到达，单次P99样本数仍按实际正确结果检查 |
| 预算 | 固定窗口约132分钟，另需准备、检查、身份握手和收尾；整任务8小时上限，默认total模式，可配置，预留100秒清理 |
| 证据与磁盘 | 新证据上限4GiB、宿主剩余至少80GiB；耗尽保留完整分母/部分结果，不减题或缩窗 |

4CPU与6CPU用于观察增加可用CPU是否仍显著改变结果，GOMAXPROCS保持4。四个臂依次执行；最高driver6CPU加provider1CPU，宿主另留空间给控制器和常驻服务。全机独占仍不作承诺，保留CPU特征、I/O、常驻服务和虚拟化信息。

当前VM未暴露AVX/AVX2/SHA-NI；固定Go1.27.3源码在该条件下走SHA256通用实现。原语诊断观察到1MiB纯SHA256约8.4–8.6ms；这是开发成本定位，不能等同真实HG瓶颈占比。该特征进入新环境记录，不能据当前VM结果概括所有Go部署。

## 判断规则

沿用Go已有资源与质量定义：全部计划到达保留，正确性/错误/丢弃/迟到均独立检查，进程与实际cgroup身份、CPU/RSS、配额和节流可核验；phase CPU份额超过80%、出现节流或缺少原始资源证据都不能通过驱动门。预热与测量分别检查，完整结果和未达范围保留。

4CPU与6CPU、两个block间的P99按原headroom工程容差`max(1ms, 10% × 两值较小者)`逐题/逐编码比较；窗口P50/P95沿原预热过渡规则。只有相应单元完整、质量与资源合格、provider无已知压力且资源对照稳定时，才给出限定条件的工程通过。统计置信、误报率认证与服务器性能结论继续单列；没有将不确定的旧结论改判。

真实HG仍需同binary/执行策略、同资源声明，以及每个负载点自己的完整正确性、完成窗吞吐、延迟、错误/拒绝、CPU/配额/节流/RSS与环境证据。fixture通过但真实HG存在驱动压力时，该点仍不能用于服务器容量结论。真实HG过载点保留原曲线与停止/未知分类。

真实HG后续A/A和正控制继续使用自己的新数据及原既定判断规则；三代表题观测成本保留原批准范围，其余八题仍未知。正式全11题×4速率探索、独立4对/8个新JVM确认、forward/embedded及SF100范围不变。
