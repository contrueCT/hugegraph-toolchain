# 默认HTTP执行链的收敛

默认执行链保留工作负载、完整答案、计时、计数和生命周期，并减少默认路径中的重复准备与证明。普通运行报告为描述性结果，完整性能资格与 SF100 实测单独验证。

```text
一份profile
    |
CLI：校验一次，保存一份输入/题集，提交一个现有task
    |
task：唯一状态 + 进程组监护 + 一个整次执行预算
    |
workflow：前检 -> 独立测量进程 -> 后检 -> 原始清单 -> JSON/HTML
           同进程组织；每次测量仍独立，计时/校验/连接语义保持
```

| 职责 | 精简前 | 精简后 |
| --- | --- | --- |
| 准备 | Node/Go分别实现目录、附件、题集复制和task模板；普通入口重复读取profile | 共用`http-plan.ts`；普通入口复用一次校验结果 |
| 输入材料 | plan和raw各复制一份profile/题集/Go注册信息 | 普通运行只有`evidence/`一份独立输入/题集，原地执行；runner请求仍携带原协议要求的配置以自校验，高级plan兼容保留 |
| task描述 | 先写task.source再读回冻结，另写task.json后普通入口又读回提交 | 共用内存freezer，直接提交；任务库的plan.json是唯一冻结task副本 |
| 应用状态 | intent.json和run.json同时保存提交信息，另有task状态 | 一个原子更新的run.json保存提交键/确定的task ID/结果指针；运行状态仍只在task库 |
| 探针/报告 | 前检、后检和分析分别启动额外Node进程 | 复用已有函数，在workflow内执行；独立测量进程保留 |
| Go身份 | 规划/工作流核对后，每个探针和测量还启动version进程 | 规划和工作流各核对一次；原生runner每次发HTTP前仍核对实际SHA/构建，完整raw校验保持 |
| 报告校验 | raw清单核过的探针/题集成员在嵌套reader内再次hash | 一个reader先逐成员核验，再绑定嵌套清单；答案、计数、时序和语义校验仍全部执行 |
| 截止/取消 | 普通入口无显式整次预算，停止后可能缺少报告 | `--budget-ms`与默认total，预留清理；取消、截止和前检失败生成partial JSON/HTML，保留全部计划分母 |

以11题、一个负载、一次重复、前后检查开启的正常运行计算固定执行子进程；不计启动CLI和平台相关的状态查询：

| 项目 | 精简前 | 精简后 |
| --- | ---: | ---: |
| 用户维护配置 | 1个profile | 1个profile |
| 持续Node控制进程（task worker、guardian、workflow） | 3 | 3 |
| 单独的Node探针/分析进程 | 3 | 0 |
| Node执行器测量进程 | 11 | 11 |
| Go原生HTTP进程（22检查+11测量） | 33 | 33 |
| Go独立version进程（不含一次性的注册） | 35 | 2 |
| 默认额外宿主握手/跨进程时钟证明 | 0 | 0 |

因此，Node路径固定执行子进程从17降到14，Go路径从74降到38。这里是协议和调用路径的确定数量，不是性能改善结论。每个Go进程内部的自身摘要核对保留；没有改变完整正确性、连接重置、进程级GC隔离、预热、到达计划或测量边界。

通用task保留worker和guardian两个小进程：worker持久化状态、处理断线恢复；guardian负责独立截止、管道上限和进程组清理，worker消失时仍收束子进程。它们承担后台运行和准确取消的不同职责。原始清单保留完整性与离线报告用途，task清单保留排队后执行前的配置/组件防漂移用途；不再叠加一套默认资格证明。

普通Node使用进程内单调计时，Go使用time.Time单调时间。JVM/collector事件归因、宿主时钟交换、逐逻辑运行的hostIdentityGate和正式比较编排均由高级流程显式使用。普通入口不静默移除用户配置的Go握手要求；需要该要求时明确转向受控流程。

与Nebula Bench/k6/Rally相比，保留的额外职责主要是每个响应的完整答案、全部计划到达、可恢复的后台任务和原始证据报告。没有要求普通运行先完成A/A、噪声认证、完整源码多次归档或精细JVM证明。部署控制与正式成绩政策继续单列；第一版不据功能通过授予容量或性能优势。

partial报告只对可完整核验的运行给出原值；未完成数据明确列为unfinished，缺项列出原题目/负载/重复，整体sampleAccounting为partial、性能资格false。原有完整输入的严格核验路径保持，损坏原始记录仍拒绝生成有效报告。
